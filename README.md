**A股量化回测系统 — 基于LSTM的多任务学习策略**
## 📖 项目简介

本项目构建了一个**完整的 A 股量化回测系统**，核心是一个基于 **LSTM 的多任务学习模型**，同时预测股票次日**收盘价**（回归任务）和**涨跌方向**（分类任务）。

系统实现了 **“数据获取 → 模型训练 → 策略回测 → 批量筛选 → 白名单生成”** 的完整闭环。通过 **baostock** 获取稳定的历史行情数据，并设计了 **止盈止损**、**动态阈值** 等风控机制。

---

## 🎯 核心特性

- ✅ **多任务学习架构**：共享 LSTM 底层，同时优化回归和分类任务
- ✅ **丰富技术指标特征**：包含 RSI、布林带、动量、成交量等 40+ 个特征
- ✅ **工程化策略设计**：结合止盈止损、动态阈值，实现风险可控的交易
- ✅ **双数据源容灾**：以 baostock 为主，内置重试机制，确保数据稳定
- ✅ **批量回测与白名单**：支持全市场批量回测，自动筛选优质股票
- ✅ **完整评估体系**：总收益率、最大回撤、夏普比率、超额收益（vs 沪深300）

## 📂 项目结构

```text
.
├── stock_full2.py              # 主程序（训练 + 回测）
├── batch_backtest.py           # 批量回测（并行 + 重试 + 白名单）
├── requirements.txt            # 依赖清单
├── README.md                   # 项目说明
├── .gitignore                  # Git 忽略文件
│
├── stock_data_cache/           # 数据缓存（自动生成）
├── model.pth                   # 模型权重
├── scaler_X.pkl                # 特征标准化器
├── scaler_y.pkl                # 标签标准化器
├── whitelist.csv               # 白名单（自动生成）
├── batch_results.csv           # 批量回测结果（自动生成）
└── backtest_result.png         # 资金曲线图（自动生成）
├── analyze_results.py            # 回测结果深度分析（统计 + 可视化）
├── analysis_output/              # 分析结果输出目录（自动生成）
│   ├── return_distribution.png   # 收益率分布图
│   ├── return_vs_drawdown.png    # 收益 vs 回撤散点图
│   ├── trade_count_distribution.png # 交易次数分布图
│   ├── sharpe_by_return_group.png  # 夏普比率分组箱线图
│   ├── statistics_summary.csv    # 统计摘要
│   └── descriptive_stats.csv     # 描述性统计



🚀 快速开始
1. 安装依赖
pip install -r requirements.txt

2. 单只股票回测
python stock_full2.py
程序会交互式询问股票代码，自动完成：
数据获取（baostock，支持重试）
特征构造（40+ 技术指标）
LSTM 训练（50 轮）
策略回测（含止盈止损）
生成资金曲线图（含沪深300对比）

3. 批量回测与白名单生成
python batch_backtest.py
程序会：
统一获取沪深300指数数据（所有股票共用）
并行回测指定数量的股票
自动重试失败股票（最多3次）
生成 batch_results.csv 和 whitelist.csv
💡 你可以在 batch_backtest.py 顶部修改 MAX_STOCKS_FULL 控制测试数量，首次建议设为 20 快速验证。

4. 回测结果深度分析
python analyze_results.py
程序会：
自动加载 batch_results.csv
生成收益率分布、收益 vs 回撤、交易次数分布等图表
计算核心统计量（正收益占比、平均收益率、夏普比率等）
筛选并生成白名单 whitelist.csv
输出相关性检验（收益率与回撤的关系）

🔧 策略参数调优
你可以在 stock_full2.py 顶部自由调整核心参数：
BUY_THRESHOLD = 0.52      # 上涨概率高于此值买入
SELL_THRESHOLD = 0.48     # 上涨概率低于此值卖出
STOP_LOSS = -0.10         # 亏损 10% 时强制止损
TAKE_PROFIT = 0.30        # 盈利 30% 时强制止盈
白名单筛选参数（在 batch_backtest.py 中）：
WHITELIST_MIN_RETURN = 0.30    # 最低收益率（30%）
WHITELIST_MIN_TRADES = 3       # 最少交易次数（3次）
WHITELIST_MAX_DRAWDOWN = 0.50  # 最大可接受回撤（50%）

📊 结果可视化
运行结束后自动生成：
资金曲线对比图 (backtest_result.png)：策略 vs 沪深300
交易明细（终端打印）
最大回撤 / 夏普比率 / 超额收益（终端打印）
